# Portfolio (black & cyan theme)

This is a minimal static portfolio scaffold with a black/cyan theme and an animated computer icon that displays streaming, code-like lines.

Files:
- `index.html` — main page
- `styles.css` — theme and animation styles
- `script.js` — generates streaming code lines inside the computer screen
 - `image/` — folder for avatar and other images (place photos here)

How to run
1. Open `d:/Study/Code/Portfolio/index.html` in your browser (double-click or right-click -> Open with).

Notes & next steps
- Replace `Your Name` in `index.html` with your real name.
- Add links below the title to your projects, GitHub, resume, etc.
- If you want the animation to show actual code snippets or project names, modify `script.js` to use your real snippets.
 - To add photos, put them into the `image/` folder and update the `src` in `index.html` as needed.
